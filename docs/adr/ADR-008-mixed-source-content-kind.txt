ADR-008 Смешанный тип содержимого версии источника
Статус: accepted (GPT, canonical contract owner), требуется проверка Claude при регенерации 1.1.0.
Дата: 2026-10-29.

ПРОБЛЕМА
ADR-004 задал SourceReadiness.content_kind как один enum без значения mixed. При этом
принятый исследовательский пакет DR-06 намеренно хранит в одной неизменяемой версии
несколько разных артефактов: 110 геометрий зданий, таблицу временного ряда ERA5,
82 строки каталога Sentinel и таблицы коэффициентов. Обозначить такую версию как
imagery_catalog, vector, model_timeseries или table означало бы скрыть остальные
части и дать UI неверное утверждение о содержимом.

РЕШЕНИЕ
В 1.1.0 добавить additive значение content_kind="mixed". Поле applicability обязано
перечислять фактические виды и ограничения смешанной версии. Это не делает набор
пригодным для расчётов: readiness_state=research_unverified и DataGap сохраняются.
Новые импорты по возможности разделяют разные продукты на отдельные DatasetVersion,
но миграция уже принятого checksum-verified receipt не переписывает его идентичность.

ПОСЛЕДСТВИЯ
- DR-06 публикуется в read model как mixed, не как готовый raster_product.
- Старые версии с неизвестной структурой мигрируются как mixed с явной пометкой,
  record_count=null и без утверждения о полноте.
- Полный слой 47 974 зданий по-прежнему отсутствует и не выводится из числа preflight.
