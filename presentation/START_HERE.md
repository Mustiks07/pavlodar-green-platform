# Pavlodar Green — комплект для жюри

1. Откройте `Pavlodar_Greening_Final.pdf` для быстрого просмотра без PowerPoint.
2. Откройте `Pavlodar_Greening_Final.pptx` для полноэкранной презентации.
3. На слайде «Платформа за 60 секунд» нажмите на изображение карты — ролик уже встроен. Отдельный файл `Pavlodar_Greening_Demo_60s.mp4` приложен для резервного показа.
4. Для живого показа следуйте `QUICK_DEMO_GUIDE.md`.
5. Текст выступления находится в `JURY_PITCH.md`, ответы на вопросы в `JURY_QA.md`.

## Вход в локальную платформу

После запуска `tools/dev/start-demo.ps1` терминал печатает локальный пароль. Пользователь специалиста: `specialist`. Пароль намеренно не хранится в этом комплекте.

## Главная демонстрация

Карта → водосберегающий проект → полный расчёт → сравнение → городская программа → ИИ-ассистент → 3D → исполнение и отчёт.
