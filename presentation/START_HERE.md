# Pavlodar Green — комплект для жюри

1. Откройте `Pavlodar_Greening_Competition_v7.pdf` для быстрого просмотра без PowerPoint.
2. Откройте `Pavlodar_Greening_Competition_v7.pptx` для полноэкранной защиты.
3. Основной пятиминутный сценарий, включающий живой показ приложения, резервные короткие версии и ответы на вопросы находятся в `PITCH_AND_QA_RU.md`.
4. Перед защитой один раз пройдите полный пятиминутный маршрут из того же файла на локальном стенде.

Старые материалы сохранены как архив, но не входят в основной путь жюри. Конкурсная версия использует актуальные снимки продукта и не зависит от встроенного видео.

## Вход в локальную платформу

После запуска `tools/dev/start-demo.ps1` терминал печатает локальный пароль. Пользователь специалиста: `specialist`. Пароль намеренно не хранится в этом комплекте.

## Главная демонстрация

Карта → водосберегающий проект → полный расчёт → сравнение → городская программа → ИИ-ассистент → 3D → исполнение и отчёт.
